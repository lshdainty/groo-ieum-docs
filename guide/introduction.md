# 소개

## 그루 이음이란?

**그루 이음**은 사람을 숫자로 관리하는 도구가 아니라, 사람과 사람, 사람과 회사의 **관계와 맥락을 잇는** HR 서비스입니다. 그루의 서비스 중 하나입니다.

> "사람과 사람, 사람과 회사의 모든 순간을 단단하게 이어줍니다."

## 이음이 지향하는 것

한 사람이 회사에 뿌리내릴 때 동료와의 신뢰를 잇고, 회사의 방향과 개인의 성장을 잇습니다. 흩어진 인사 행정을 하나로 묶되, 사람을 중심에 둡니다.

- **관리가 아니라 연결** — 관리당한다는 피로감 없이, 팀 안에서 함께 자란다는 안정감을 줍니다
- **필요한 만큼, 단정하게** — 일정 · 휴가 · 결재 같은 기본기부터 튼튼하게 다집니다
- **각자의 쓰임을 지키며** — 서로 다른 사람과 팀이 같은 방식을 강요받지 않습니다

## 주요 기능

- **📅 일정관리** - 구성원들의 근무 및 휴가 일정을 캘린더로 관리
- **🏖️ 휴가관리** - 휴가 발생, 사용, 잔여 일수 체계적 관리
- **📝 전자결재** - 연장 근무 사전 결재 및 승인 처리
- **🔐 권한관리** - 역할 기반 접근 제어(RBAC)

- **모바일**: 반응형 웹 지원
